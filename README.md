# NOVA VIDEO AUTOPILOT

A mobile-friendly, on-demand AI video production project.

## Project goals

- Generate video concepts and research notes from a user prompt.
- Draft scripts, narration, and scene plans.
- Organize visual, audio, subtitle, and editing stages.
- Export a finished MP4 when the required media services are configured.

## Principles

- On-demand execution; no always-on background process by default.
- Mobile-first control panel.
- No paid API or service is enabled without explicit approval.
- Keep API keys and secrets out of the repository.
