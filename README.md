# NOVA VIDEO AUTOPILOT

A mobile-first, on-demand video production workspace. The current focus is MØNO — Episode 001: THE ARRIVAL.

## Project goals

- Plan scenes, narration, sound and subtitles.
- Keep a consistent character identity across shots.
- Assemble user-approved media into a finished video.
- Prefer local/free tools and transparent production status.

## Principles

- No paid API, subscription, trial, or AI quota is used without explicit approval.
- Keep API keys and secrets out of the repository.
- Never label a storyboard, placeholder, or text-card render as a finished cinematic video.
- Prefer mobile-first workflows and local media handling.

## Current status

- Story and shot plan: drafted.
- Character identity specification: documented.
- NOVA browser prototype: available under `frontend/`; its current canvas renderer is a basic WebM prototype, not the finished episode.
- Cinematic scene clips and final voice tracks: not yet produced.
- MP4 export: not yet implemented.
- Piper narration API: backend code exists but requires deployment and voice models; GitHub Pages alone cannot run it.

## Free production policy

The first suggested Android editor is LibreCuts via its official F-Droid listing. It is beta software; test a short clip before using it for a final export. No paid provider should be invoked without explicit approval.
